# 判例らくがき帳

憲法・行政法・民法の判例を、1事件1ページで見る簡単な電子本です。

## 見る方法
- `index.html` を開く
- GitHub Pages を有効にするとWebで公開できます（Settings → Pages → Deploy from a branch → main / root）。

## 追加方法
1. `images/002-xxxx.svg` などにイラストを追加
2. `pages.js` の配列に事件名・説明・画像パスを追加
3. 次へ・前へボタンで自動的にページをめくれます

初回は宇奈月温泉事件です。GitHub連携でPNGを直接アップロードできなかったため、当日の画像とは別の簡易SVGを仮置きしています。元画像は手元のZIP版から差し替え可能です。
